# DEV PCSX2 PRO

![logo](https://raw.githubusercontent.com/PCSX2/pcsx2/e75632ddef2f8aaef4e9a83fc6ee36d2745400eb/pcsx2/gui/Resources/BackgroundLogo.png)

Is the PCSX2 1.7.2084 build with advanced Debugger Tools like Function Call Tree Graph, Function Graph View, Export Disassembly to Txt(from memory interval),
Restore and Set Nop at Instructions and the most great of all: Per-Game Overlay Options with Matching Binary header and Custom Symbols by overlay region and Function/Instructions Detection.

And a surprise! CHEATS/WIDESCREEN PATCHES HOT-RELOAD! (Detect as the file is modified in the disc)

## Why would i use an older version for debugging or develop?

Double click to follow the code block(instruction block) and click arrow to highlight!

Setup memory regions to be analyzed by the PCSX2 debugger and get those instructions/functions.

Download on the Release section, for higher compatibility purposes, the build is x86(32 bits).

## System Requirements

PCSX2 supports Windows, Linux, and Mac platforms. Our [setup documentation page](https://pcsx2.net/docs/setup/requirements) contains additional details on software and hardware requirements.

Please note that a BIOS dump from a legitimately-owned PS2 console is required to use the emulator. For more information, visit [this page](https://pcsx2.net/docs/setup/bios/).
